# 给云端 AI 的填写指令（模板）

> **用法**：把本文件 + 对应的「空模板」 + 你手上的原始材料，一起发给云端 AI（任意大模型）。
> AI 会按固定格式产出数据文件；拿回来跑校验即可。
> **规范正本**：`docs/数据格式规范_v1.md`　**校验**：`node tools/validate_data.mjs <文件>`

---

## ⬛ 通用指令（所有类型都先贴这一段）

```
你是数据整理助手。任务：把我提供的原始材料，转换成我指定的固定格式文件。

【最高优先规则】
1. 只输出文件内容本身，不要任何解释、前言、结语、代码围栏（```）。
2. 严格使用我给定的字段名（中文），一个字都不要改、不要增删字段、不要改字段顺序。
3. 缺失的信息留空，不要编造。宁可留空，也不要猜。
4. 字符串里如果包含逗号、换行或双引号，必须用双引号包裹整个字段，内部的双引号写成两个（""）。
5. 值为数字的字段（如 成员数、句长上限、覆盖目标）只写数字，不要带单位、不要加引号。
6. 全部英文词一律小写。

【完成后自检，逐条回答】
- 字段名是否与我给的模板完全一致？
- 有没有我明确要求"不要编造"而你其实猜了的地方？（逐条列出）
- 有没有无法归类、需要我确认的条目？（列出来，不要硬塞）
```

## ① 词库 `<班级>`

```
请把下面的词表材料转成《词库》格式（CSV，带 BOM，逗号分隔）。

表头（务必按此顺序，不要改）：
词,类型,词性,释义,来源册,来源单元,音标,备注

字段规则：
- 词：单词或短语。短语整词保留（如 bring about），不要拆开。**多词短语里的词序不要改。**
- 类型：只能填这 5 个值之一 —— 单词 / 课标词 / 短语 / 句型 / 待定词
    · 单词  = 教材单元词
    · 课标词 = 来自《义务教育英语课程标准》三级词表
    · 短语  = 多词短语
    · 句型  = 句式/句型模板
    · 待定词 = 来源待证、尚未通过核对的词
  ⚠️ 这个字段有语义后果：只有 单词 / 课标词 / 待定词 会被当作"学生已学"。不确定时填「待定词」，不要填「单词」。
- 释义：中文。同一词只能给一条最完整的释义（用「；」连接多个义项）。
- 来源册：教材册次（八上/八下/九上…）或「课标1600」。**必填，不能空。**
- 音标：可留空。

⚠️ 同一个词只允许出现一行。如果它在多个来源册出现，合并成一行，来源册用「；」连接（如 九上；课标1600）。

原始材料：
（把材料贴在这里，或说明附件）
```

## ② 分层与调适参数 `<班级>`

```
请把下面的班级分层信息转成《分层与调适参数》格式（JSON）。

输出结构（不要增删字段名）：
{
 "_meta": {
  "schema版本": "1",
  "数据版本": "v1",
  "名称": "（班级名）分层与调适参数",
  "生成": "（今天日期 + 数据来源）",
  "口径": "组级参数，由 画像_<班级>.json 折算",
  "红线": "含学生信息，只存本地，绝不进入公开仓"
 },
 "groups": [
  { "id": "组:A", "名称": "A层", "类型": "组", "成员数": 33,
    "句长上限": 20, "覆盖目标": 95, "生词率上限": 3,
    "支架密度": "中", "已学词": [], "到期词": [] }
 ]
}

字段规则：
- id：唯一，格式「组:X」或「人:姓名」
- 类型：只能填「组」或「人」
- 成员数 / 句长上限：必须是正整数（25，不是 "25 人"，也不是 "二十"）
- 覆盖目标：0–100 的整数
- 支架密度：中 / 密 / 重
- 已学词 / 到期词：字符串数组，没有就写 []

原始材料：
（把分层信息贴在这里）
```

   "生成":"（日期+来源）", "口径":"域级得分率=多次考试分值加权",

⚠️ 这是学生真实数据。请只在本机保存，不要上传到任何公开位置。

## ④ 书级知识库 `<书名>`

```
请把下面的评审/审校记录，整理成《书级知识库》格式（CSV，带 BOM）。

表头（不要改）：类型,词,值,来源数

字段规则：
- 类型：只能填「加注词」或「换词倾向」
- 词：英文，**必须小写**
- 值：加注词填中文释义（2–6 字）；换词倾向留空
- 来源数：该词被确认的次数（数字）
- ⚠️ 释义不能填「复现」「复数」「比较级」这类流程标记 —— 那些不是释义，程序会当无效数据丢掉。

原始材料：
（贴审校记录）
```

## ⑤ 注释词典 `<书名>`

```
请把下面的词→释义对应关系，整理成《注释词典》格式（CSV，带 BOM）。

表头（不要改）：词,释义,来源

字段规则：
- 词：英文，小写
- 释义：中文，2–6 个汉字，初中生能懂
- 来源：填「教师知识库」或「归一（多数票）」
- ⚠️ **一个词只允许一条释义**。这是硬规则：同一本书里同一个词在不同章节出现不同中文，会让读者困惑（本项目曾出现 223 个词型一词多义，已修）。

原始材料：
（贴词与释义）
```

## ⑥ 专名表 `<书名>`

```
请从下面的材料里，列出这本书的**专有名词**（人名、地名、作品名、机构名）。

输出：纯文本，一行一个，**全部小写**，多词名用空格分隔。
不要序号、不要引号、不要解释。以 # 开头的行是注释。

示例：
napoleon
snowball
animal farm
england

⚠️ 专名表的作用是：这些词在质检时不计入生词，改写时也不加中文注释。所以**必须列全**——
本项目曾漏掉三个主要人物，导致把马名 Clover 注成了"三叶草"。

原始材料：
（贴或列出书里的专名）
```

## 发回来之后

```bash
node tools/validate_data.mjs <收到的文件>
```

- 通过 → 直接进管线
- 不通过 → 把报错原文贴回给 AI，让它修，再验一次

**校验不通过就不要用**——这是"AI 生成 + 确定性检查"的闸门，和文本生成一个道理。
