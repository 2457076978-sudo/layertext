# 模板包 · 使用说明

> 这个包是给**别的老师**（以及他们的 AI）用的：把自己班的数据填成固定格式，然后交给 LayerText。
> 格式规范正本：`../docs/数据格式规范_v1.md`

## 一、包里有什么

| 文件 | 用途 |
|---|---|
| `00_AI填写指令.md` | ⭐ **把这段提示词和空模板一起发给云端 AI**，让它按格式填 |
| `词库_空模板.csv` / `词库_示例.csv` | 学生已知词表（判定"学过没有"的唯一锚） |
| `分层_空模板.json` / `分层_示例.json` | 班内分组与调适参数（句长上限、覆盖目标） |
| `画像_空模板.json` / `画像_示例.json` | 逐生成绩与学情 |
| `知识库_空模板.csv` / `知识库_示例.csv` | 每本书一份：加注词 + 换词倾向 |
| `词典_空模板.csv` / `词典_示例.csv` | 每本书一份：跨章统一释义 |
| `专名_空模板.txt` / `专名_示例.txt` | 每本书一份：人名地名作品名 |

**示例文件全部通过校验**，可以照着改。

## 二、要准备哪几个文件

| 文件 | 谁来产生 | 从哪来 |
|---|---|---|
| 词库 | 脚本转换（**AI 不得编造**） | 课标词表 + 教材词表 |
| 画像 | 脚本转换 | 考试成绩（含小题分）→ ETL → 聚类 |
| 分层 | 脚本转换 + 教师裁决 | 由画像折算 |
| 原著原文 | 老师提供 | 需规范化（分段、清洗） |
| **知识库 / 词典 / 专名** | **AI 填 + 校验** | 随教学与审校累积 |

## 三、流程

```
① 打开 00_AI填写指令.md，找到对应类型的那段提示词
② 把「提示词 + 空模板 + 你的原始材料」一起发给云端 AI
③ AI 产出文件 → 存到本机
④ 跑校验：
     node tools/validate_data.mjs <文件>
⑤ 通过 → 进管线；不通过 → 把报错贴回 AI 让它改，再验一次
```

## 四、四条硬规矩

1. **字段名一个字都不能改**——程序按字段名读数据；
2. **不确定就留空或填「待定词」，不要编造**——猜错比留空危害大得多；
3. **一个词只允许一条释义**（词典）、**同一词只允许一行**（词库）；
4. **校验不通过就不要用**——这是"AI 生成 + 确定性检查"的闸门。

## 五、红线（涉及学生数据）

`画像` 和 `分层` 含**学生真实信息**：

- 只存本地，**不上传任何公开位置**、不进公开仓库；
- 遵守所在学校与地区的未成年人数据规定；
- 分享给他人时，先脱敏（`_meta.红线` 字段里已写明这条约定）。

## 六、有问题看哪

| 想知道的 | 看 |
|---|---|
| 字段是什么意思 | `../docs/数据格式规范_v1.md` 第二节 |
| 为什么格式不能改 | 同文件第三节「冻结清单」 |
| 校验报错怎么读 | 跑 `node tools/validate_data.mjs <文件> --json`，按字段定位 |
