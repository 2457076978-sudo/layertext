# 快速开始 · 从零到产出你的第一版分层材料

> 给**第一次用这个工具的老师**。目标是：**换一本名著 + 你自己的班 → 三档可读文本**。
> 深度说明见 `数据格式规范_v1.md`；本文件只讲最短路径。

---

## 0. 你需要先想清楚的三件事

| 问题 | 为什么重要 |
|---|---|
| **你要做哪本书？** | 决定原文从哪来、专名表列什么 |
| **你要给几个梯队做？** | 决定生成几档、每档的句长与词汇边界 |
| **你的学生学到教材哪儿了？** | 决定"哪些词算学过"——这是全流程的词汇边界 |

第三件事以前最难，现在只需一句话，例如 **"人教版，上到八下 Unit 5"**。

## 1. 装环境（一次性）

```bash
# ① node（本机不在默认 PATH）
export PATH="$HOME/.local/node-v22.23.2-darwin-arm64/bin:$PATH"

# ② 引擎
cd <你的 LayerText 目录>
npm install && npm run build

# ③ AI 配置：~/.layertext.json 填 baseUrl，钥匙串存 API key
security add-generic-password -s layertext.apikey -a $USER -w '你的key'
```

## 2. 建一个"调适项目"

**只改一个 JSON**，其余全部由它派生。

```bash
cd <你的 LayerText 目录>
cp templates/调适项目_模板.json ~/我的项目/调适项目_我的书.json
```

打开它，填这几项：

```jsonc
{
  "书名": "Animal Farm",
  "工作区": "/绝对路径/我的书工作区",
  "调适工作区": "/绝对路径/我的书工作区/调适工作区",
  "原文目录": "/绝对路径/…/原文重制_M50",       // 放 第X章/原文_规范化.md
  "产物目录": "/绝对路径/…/重制三版",
  "词库": "/绝对路径/…/已知词汇库.csv",
  "引擎目录": "/绝对路径/LayerText",
  "教材单元库": "/绝对路径/…/教材单元_人教版.json",
  "教材进度": "八下:U5",                        // ← 语义：学生已学到八下 Unit 5
  "书级": {
    "专名表": "/绝对路径/…/专名_我的书.txt",
    "知识库": "/绝对路径/…/知识库_我的书.csv",
    "词典":   "/绝对路径/…/词典_我的书.csv"
  },
  "产物命名": { "A": "A层85", "M": "M层75", "B": "B层60" },
  "日期": "2026-09-10"
}
```

之后所有命令加 `--project ~/我的项目/调适项目_我的书.json`，或设环境变量：
```bash
export LAYERTEXT_PROJECT=~/我的项目/调适项目_我的书.json
```

## 3. 准备五份数据

| 文件 | 谁产生 | 怎么做 |
|---|---|---|
| **词库** | 脚本/AI 整理 | 课标词表 + 你的教材词表。**AI 不得编造**，且必须核对 |
| **专名表** | AI 填 + 校验 | 这本书的人名/地名/作品名，一行一个，小写 |
| **知识库** | AI 填 + 校验 | 加注词 + 换词倾向（新书从空开始，随审校累积） |
| **词典** | AI 填 + 校验 | 跨章统一释义（同上） |
| **原文** | 你提供 | 需规范化成 `第X章/原文_规范化.md`，段落带 `[P01]` 标记 |

**AI 填的三份**，用 `templates/00_AI填写指令.md` 里的提示词：
```
① 把提示词 + 空模板 + 你的原始材料 一起发给云端 AI
② 拿回文件 → node tools/validate_data.mjs <文件>
③ 通过就用；不通过 → 把报错贴回 AI 让它改
```

**校验不通过就不要往下走。**

## 4. 检查教材进度算得对不对

```bash
node tools/textbook_units.mjs progress 教材单元_人教版.json --at "八下:U5" --out /tmp/check.txt
```

会打印基础层 + 每册每单元各加了多少词，并产出：
- `check.txt` —— 已学词表
- `check_语法.md` —— 已学语法清单

**先看这两个文件对不对**，再往下做——**项目配置里的 `教材进度` 一旦填上，它就是 QC 的已知词口径**
（`loadLexicon()` 会把这份已学词并进词表；不填 = 沿用整册词库口径，两者结果不同、都要在报告里声明）。

> 「（未标单元）」的词：**本册已学完**就整册计入；**本册未学完**则不计入（无法判断来自哪个单元）。
> 输出里会明写这一行，别以为它被漏掉了。

## 5. 跑管线（一条命令七步）

管线脚本在**引擎仓库**里：`tools/af_pipeline/`。

```bash
# 先看计划（不执行）
node tools/af_pipeline/LayerText_AF管线.mjs --dry

# 跑全流程：规范化 → 生成 → 精修 → 补注 → 修复 → 复核 → 台账
node tools/af_pipeline/LayerText_AF管线.mjs

# 只试一章（省额度）
node tools/af_pipeline/LayerText_AF管线.mjs --tier M --chapters 1
```

| 步骤 | 干什么 | 要不要 AI |
|---|---|---|
| 规范化 | 原文 → `[P##]` 分段 md（补缺空格、清 OCR 章节名残留） | 否 |
| 生成 | 逐段改写（篇幅守恒）+ 知识库注入 | **是** |
| 精修 | 注释轮 + 数字/专名缺失补回 | **是** |
| **补注** | 按 QC 判定的 OOV 把注释补齐（先查词典，缺的才问模型） | **是**（命中词典则几乎不花钱） |
| 修复 | 专名误注 / 字面 `[P##]` / 嵌套注释 / 同词多义 / 缺空格（幂等） | 否 |
| 复核 | 按各层句长上限重算 QC，**含加注覆盖率闸门** | 否 |
| 台账 | 逐句对照（保留/改写/删句、数字专名缺失清单） | 否 |

> ⚠️ **生成 / 精修 / 补注** 三步会调用 AI，**消耗额度**。
> 建议先 `--chapters 1` 跑通一章，确认效果再做全本。
> **复核**这一步带闸门：任何章次加注覆盖率 < 70% 会让管线以退出码 1 中止。

## 6. 看结果

| 文件 | 看什么 |
|---|---|
| `产物目录/第X章/原文_<层>_<日期>.md` | 成品正文（含 `word（中文）` 内联加注） |
| `产物目录/三档汇总_<日期>.md` | 各层篇幅/生词率/句长/黑名单/超限句 |
| `产物目录/台账_<层>_<日期>.md` | 逐句对照：保留/改写/删句，**数字专名缺失清单** |

**先看台账的「数字/专名缺失」节**——那是最可能出事实错误的地方。

## 7. 教师审校

打开 **LayerText App** → 打开产物章节文件 → 逐章过难句（已标红）→ 标记。
App 会按目录里的工作区配置自动绑定该层的口径。

## 换一本书 / 续跑 / 覆盖率口径

详见 [换书与续跑说明](换书与续跑说明.md)：调适项目的每个字段、词库的四个历史坑、
`--resume` 到底认什么（只认门禁通过的 `done`）、哪些产物会被覆盖哪些不会、
以及报告里四个"覆盖率"各自的分子分母（**生成覆盖率单独展示是误导**，成色看最终覆盖率）。

## 常见坑（本项目实测）

1. **AI 模型必须用非思考型**（如 `deepseek-chat`）。思考型模型会把推理过程混进正文。
2. **加注格式不许改**：必须 `word（中文）`、全角括号、词与括号间无空格。改了全项目解析会坏。
3. **`[P##]` 段落标记不许丢**：它是段落对齐与 App 的稳定锚。模型有时会吐字面 `[P##]`，跑一次「修复」步骤即可补回。
4. **专名表必须列全**：漏一个主要人物，就会把马名注成普通名词（本项目曾把 `Clover` 注成"三叶草"）。
5. **判定"已学"要用 `课标1600 ∪ 词库`**，不能只用词库——词库可能漏收基础词。
6. **改动必须当天登记**，否则审计链断了，出问题回溯不了。
7. **加注不是"注了多少处"，而是"该注的注了没有"**——汇总表的「加注覆盖率」低于 70% 会直接判不通过；
   补注用 `LayerText_AF补注.mjs`（QC 判定的 OOV → 先查词典 → 缺的才问模型）。
8. **不要把整套管线脚本复制到工作区**：脚本正本在引擎仓库 `tools/af_pipeline/`，
   工作区里放副本就会"改了不生效"。

## 一条命令速查

```bash
export PATH="$HOME/.local/node-v22.23.2-darwin-arm64/bin:$PATH"
export LAYERTEXT_PROJECT=~/我的项目/调适项目_我的书.json   # 设一次即可；不设则自动向上找/记住上次用的

PIPE=<引擎目录>/tools/af_pipeline
node $PIPE/LayerText_AF管线.mjs --dry                  # 看计划
node $PIPE/LayerText_AF管线.mjs --tier M --chapters 1  # 试一章
node $PIPE/LayerText_AF管线.mjs                        # 全流程
node $PIPE/LayerText_AF补注.mjs --dry                  # 只看加注缺口，不调 API
node tools/validate_data.mjs <文件或目录> --all        # 数据校验
node tools/textbook_units.mjs progress … --at "八下:U5"   # 进度换算
```
