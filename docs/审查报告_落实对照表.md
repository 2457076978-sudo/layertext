## 本轮额外抓到并修掉的真实缺陷（都没在原报告里）

| # | 缺陷 | 为什么危险 |
|---|---|---|
| 1 | 提示词说"已注过的绝不要再注"，门禁却要每段都注 | 模型两边被打，**永远过不了关且不知道错在哪**；新门禁会大量误杀 |
| 2 | `segmentList` 把前置说明里"提到"的段号当段落（Animal Farm 第一章头部写着「[P14] 为稳定锚…」） | 幽灵段 + 索引整体错位 + "14"变成数字事实信号，**队列最前面全是假警报** |
| 3 | 段里切不出句子时 `runQc` 抛错 → 整层失败 | 一个插图占位段就能让整个运行红掉 |
| 4 | `verifyManifest` 在"0 件产物"时报「可以当作完成品引用」 | **假绿**，正是本项目要根治的那类"静默成功" |
| 5 | 决定索引的驱动加载在 ESM 里写了 `require('node:module')` → 永远静默降级，而查询用例都写着 `if (!available) return`，**空跑成一片绿** | 假的绿测试比没有测试更糟 |
| 6 | `byRule` 按 `A+B` 整串分组再拆，同一条规则出现两次、数字各算各的 | 误报率这个"规则噪音水平"的度量直接失真 |
| 7 | `appendDict` 读整份→写回整份：两位教师并行时后写的盖掉先写的 | 「明明配过的词下次又问一遍」，且不报错 |
