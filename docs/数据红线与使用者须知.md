# 数据红线与使用者须知

> 凡使用本工具处理**真实班级/学生数据**的老师，用之前请读完本文件。
> 相关：`数据格式规范_v1.md`（第六节 · 给别的老师的上手清单）

---

## 一、哪些数据是敏感的

| 数据 | 敏感级别 | 为什么 |
|---|---|---|
| `画像_<班级>.json` | 🔴 **高** | 逐生姓名 + 成绩 + 分层 + 学习困难 |
| `分层_<班级>.json` | 🔴 **高** | 含学生姓名与分层归属 |
| 分层名单 CSV | 🔴 **高** | 同上 |
| 成绩原始包 / 小分表 | 🔴 **高** | 逐生逐题 |
| `词库` / `知识库` / `词典` / `专名表` | 🟢 低 | 不含学生信息 |
| 产物文本 / 台账 / 汇总 | 🟢 低 | 不含学生信息 |

## 二、三条硬规矩

1. **只存本地。** 画像与分层文件**不得**上传到任何公开位置（含公开代码仓库、云盘公开链接、在线表格）。
2. **不进公开仓。** LayerText 是开源项目，仓库里**永远不放**学生数据。本项目在 `画像_<班级>.json` 的 `_meta.红线` 字段里已写明这条约定。
3. **分享前脱敏。** 要把数据给他人（含 AI 服务）时，先去掉姓名，用匿名编码。

## 三、匿名编码约定

学生一律用 **`层-序号`** 编码（如 `A03` / `B07` / `M12`），不写姓名。

- 编码对照表单独保存，**不随数据外传**；
- 采集表、访谈记录、小测卷一律用编码；
- 本项目的 `评价工具/02_试读信号采集表` 已按此约定设计。

## 四、关于 AI 服务

调适流程会把**待改写的英文原文**与**教师确认的知识库**发给 AI 服务。这些内容：

- 是**公版或自写文本**，不含学生信息 —— 这是安全的；
- 学生的**作答、成绩、访谈内容**不要发给 AI；
- 若确需 AI 分析学情，先聚合到班级/梯队层面并去掉姓名。

## 五、未成年人数据

目标学生为未成年人，除上述外还需：

- 遵守所在学校与地区的未成年人个人信息保护规定；
- 试读、采集、访谈**需学校与家长知情同意**；
- 研究用途的学生数据，遵循学术伦理审查要求。

## 六、技术侧已有的保护

| 机制 | 位置 |
|---|---|
| 红线声明写进数据文件本身 | `画像_*.json` / `分层_*.json` 的 `_meta.红线` |
| 画像文件不进仓库 | `.gitignore` + 约定（本项目画像存在 `01-教学工作/班级画像/`，在仓库之外） |
| 匿名编码 | 采集工具已按 `层-序号` 设计 |
| 数据面板只读本机路径 | 数据面板通过项目配置里的绝对路径读写，不外传 |

## 七、换书/换班时要注意

给别的老师用的时候：

1. **让对方自己准备自己的数据**（画像、分层、词库），你只给工具与模板；
2. **不要把你这边的画像文件打包给对方**；
3. 对方的班级数据由对方保管，遵循对方学校的规定。

---

**一句话**：工具、格式、模板可以随便传；**学生数据永远只留在本机**。
