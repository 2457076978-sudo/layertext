# QC 指标说明（为什么这样设计）

> LayerText 的自动质检（QC）引擎源自一个真实项目的三轮全书迭代（2026-09，英文原著三难度层调适），
> 每条规则都对应一个真实踩过的坑。本文说明每项指标的口径、每个句法黑名单背后的教学进度依据，
> 以及引擎如实保留的已知保守行为（漏报方向，不会误报）。

## 一、指标总表

| 指标 | 口径 | 说明 |
|---|---|---|
| ① 词表覆盖率 | 注释后口径 | 已知词 token 数 / 总 token 数。词句卡（章末生词表）首列词条并入已知——学生"读到该处已可查注" |
| ② 生词率 | 词型口径 | OOV 词型数 / 总词型数（去重后） |
| ③ 平均句长 | 词/句，另有"去歌词"口径 | 歌篇按行计，单独统计 |
| ④ 单句最长 / 超 20 词句数 | 词 | 各难度层的句长上限（如 14/16/20 词）由版本设计决定，QC 只量测不设阈值 |
| ⑤ 被动式计数 | 叙事区 | 见下"黑名单" |
| ⑥ 定语从句计数 | 叙事区 | who/which 引导 + that+实义动词型 |
| ⑦ 过去完成计数 | 叙事区 | had+分词、had+副词+分词、倒装（Never/Hardly had …）三类 |
| ⑧ 专名一致性 | — | 正文出现的专名必须出现在词句卡（专有名词要有注释） |
| ⑨ 待定词 token 命中 | 保守口径风险 | "待定词"暂计入覆盖率，但每个命中都是潜在风险点，单独计量供教师复核 |
| ⑪ **加注覆盖率** | 已注词型 / 应注词型 | **应注** = OOV 词型（去两字母词；专名已并入已知故不计）；**已注** = 正文里按 `word（中文）` 注出的词型（连字符复合词按拆开算：`blood-curdling（…）` 同时记 blood 与 curdling）。这是 **"检测 → 加注"闭环的闸门**：引擎判该注的词，产物里到底注了没有 |
| — OOV 清单 | 去重 | 词表外生词列表，供加注/替换决策 |
| — that 从句待人工复核 | — | 所有 "X that Y" 结构计数，比定从计数宽，供人工快筛 |

**⑪ 为什么要单独存在**：2026-09-10 复核发现，A 层第 7/8/9 章的加注覆盖率只有 2%（其余章 62–78%）——
引擎算得出 27% 的生词率，但当时所有报表只统计"注了多少处"，没有"该注多少"，
缺口就那样交付了出去。现在它进汇总表、进管线闸门（单章 < 70% 直接判不通过）。

"叙事区"= 剔除歌篇与直接引语后的文本：**引语只降词不降句式**（R08）——人物原话中的被动/定从
是文学锚点，改写它会失真，因此引号内文本在句法计数前整体豁免（词表覆盖仍计入）。

## 二、三个句法黑名单的教学进度依据

初中生（义务教育阶段）按教材进度尚未系统学过以下结构。对 B（支架）/M（中梯）层，
出现即计为风险；对 A（挑战）层，原型项目验证过的解禁设定是：

- **被动语态** → A 层第 5 章起解禁（对应教材相应单元已教，并配脚注说明）；
- **定语从句** → A 层第 8 章起解禁；
- **过去完成时** → 各层从严，尽量改写为一般过去时或用 before/after 明示时间先后。

> 解禁章号源自原型项目按教材单元进度做出的设计（代码内注释 U5 已教/U7 已教），
> 完整的进度对照表述将在发布版 README 中从教师操作手册补全。

## 三、防坑规则（每条都对应真实误报/漏报事故）

1. **词形还原（反向剥后缀）**：token 查词表失败后，依次尝试剥 `s / es / ies→y / ed / ing`，
   含双写辅音（stopped→stop）、去 e 型（fired→fire）。不做词干分析——目标是"这个词学生认识吗"，
   不是语言学正确的词元。
2. **不规则动词/名词全表**：sang→sing、went→go、geese→goose、teeth→tooth 等全表映射，
   后缀剥不动的不规则变化靠表解决。
3. **直接引语豁免（R08）**：见上。
4. **假阳性豁免表**：`had red / was bed / was mixed / was exhausted / was interested` 类——
   形容词或实义动词过去式，长得像被动/过去完成但不是。逐词豁免。
5. **that 三类豁免**：
   - that+时间名词（that morning/evening/something…）→ 指示代词，不是从句；
   - that+代词/系动词开头（said that he was / that the plan …）→ 宾语从句；
   - 剩余 that+实义动词（the horse that pulled…）→ 定语从句，计数。
6. **倒装句检测**：Never/Hardly/Scarcely/Seldom/No sooner + had + 过去分词。
7. **分词被动后置定语**：", lived by" / ", watched by" 型——没有 be 动词但语义被动。
8. **锚点白名单**：教师可将特定短语设为豁免（原文级锚点，如不可改写的名句），
   计数前整体替换占位。

## 四、已知保守行为（如实保留，漏报方向、不误报）

以下行为为原型引擎的真实口径，移植时原样保留（两引擎逐字段一致，见
[M1-对照测试报告](M1-对照测试报告.md)）。产品后续若要收紧，需双引擎同步修改并更新对照测试：

1. **倒装检测的窄口径**：had 与分词之间只允许恰好一个词（"Never had I seen" ✓，
   "Never had the animals seen" ✗——两个词则漏），且分词须以 -ed/-en 结尾
   （"Hardly had she spoken" ✓，"…had the bell rung" ✗——rung 不识别）。
2. **", \w+ed by" 后置被动只认规则分词**：", lived by" ✓，", built by" ✗（不规则分词不计数）。
3. **that 宾从豁免靠先行词表**：原型代码中定义的认知动词豁免表（said/agreed/knew…）实际未接线，
   "She said that surprised everyone" 会保守地计入定从（宁可多报待人工复核，不静默放过）。
4. **句法计数大小写敏感**：句首 "Was built?" / "Who lived…" 不计数（除倒装触发词已修复大小写）。
5. **不规则分词被动表有限**：`was rebuilt / were sung` 不在第二模式词表内，不计数。
6. **QC 分句不做缩写保护**：`Mr. Chen` 会在 "Mr. " 处切断（句数偏多、句长偏短）。
   审校阅读器管线另有缩写保护（Mr./Mrs./Dr./St./No.），两端口径不同——阅读器为准阅读体验，
   QC 为指标口径。
7. **er/est 比较级还原不含双写型**：nicer→nice ✓，fatter→fat ✗（词表内含 fat 也不命中）。

## 五、三态词表体系

- **已知**：课标词 ∪ 教材已学词（自定义 CSV）∪ 术语表 ∪ 不规则表 ∪ 词句卡词条；
- **待定**：类型标注为"待定词"——暂计入覆盖率，风险量由指标⑨单独计量（保守口径）；
- **词表外（OOV）**：红色标记，进 OOV 清单。

自定义词库 CSV 格式：`词,类型,词性,释义,来源册,来源单元,音标,备注`
（类型 ∈ 单词/课标词/待定词…；样例见 `examples/vocab/sample_teaching_vocab.csv`）。
