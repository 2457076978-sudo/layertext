# LayerText 质量基线

> 机器可读基线：`examples/evals/baseline.json`（`npm run eval -- --update-baseline` 维护）。
> 规则：任何改动后跑 `npm run eval`，数字**不得低于本基线**（除非书面说明理由并同步更新本文档）。

## 当前基线（2026-09-06 · W1 建立）

**QC 引擎 · 金标准对照（3 篇评测文本，68 句，45 处黑名单标注，25 个核定 OOV 词型）**

| 指标 | 基线值 | 说明 |
|---|---|---|
| 黑名单命中率 | **100.0%（45/45）** | 被动 14、定从 12、过去完成 14、超长 5，逐句与金标准一致 |
| 漏报 | **0** | 标注句未被引擎检出的数量 |
| 误报 | **0** | 未标注句被引擎误标的数量 |
| OOV 完全一致 | **3/3 篇** | 引擎 OOV 词型清单与人工核定清单逐词一致（12+9+4 词） |
| 回归测试 | **43/43 全绿** | `npm test` |
| 双引擎对照 | **95/95 项一致** | TS 与 Python 参照版（tools/compare.ts，5 篇文本含评测集） |

评测文本与标注口径见 [examples/evals/README.md](../examples/evals/README.md)。

**AI 分层初稿 · 目标特征核对（key 模式，尚未建立数值基线）**

每篇附 B/M/A 目标：B 平均句长≤12/单句≤14、M ≤14/16、A ≤18/20；三层黑名单清零（第 1 章口径）；
生词率 B≤3%、M/A≤2%；情节词必须保留（Harry/Toby、Lin/Star、Ben）。
配置 `LAYERTEXT_API_KEY` 后 `npm run eval` 输出逐项核对表；积累两轮以上数据后再定数值基线。
