3 篇自写 CC0 文本（68 句），每篇附人工标注金标准：

| 篇目 | 定位 | 覆盖 |

金标准 = 四类黑名单句子的**精确清单**（逐句与引擎比对）+ **OOV 词型全集**（每个词对照课标词表人工查证）
+ B/M/A 三层目标特征（句长/生词率/黑名单清零/情节词保留，供 key 模式核对 AI 初稿）。

### 2. `npm run eval`（src/eval.ts）

- 无 key 模式：QC 金标准对照，输出命中率/漏报/误报/OOV 对齐，与 `baseline.json` 对比，低于基线退出码 1（CI 门禁用）；
- key 模式（`LAYERTEXT_API_KEY` 环境变量）：3 篇 × 3 层实跑 AI 分层初稿，逐项核对目标特征；
- `--calibrate`：逐句打印检测明细，供标注核对/修订；`--update-baseline`：刷新机器基线；
- 报告自动落盘 `eval-reports/评测报告_<时间戳>.json`（已 gitignore）。
