# 词画卷与传播咬合 · 规划与验收标准（2026-09-18）

> 来源：09-18 功能审查第二梯队第 7 项（跨章词画卷）+ Wayne 追问"是不是可以和书本层级传播搭配起来"。
> 讨论定案：**词画卷是传播缺的那张地图（传播前预览/传播后审计/三键分治执行），传播是画卷的动作出口。**
> 每条标准机器可查：测试名、退出码或静态扫描；未达标只准标"部分完成"并列阻塞项；反作弊（禁删测试/降规则）。

**总门禁（每一项做完都要过）**：`npm run verify` 全绿（当前基线 1068 项）；涉及 `app/` 另加 `cd app && npx vite build`；涉及 MCP 另加 stdio 冒烟 tools/list 应答。

## 零、设计定案（先冻结，防走样）

1. **②类换词永不跨章改正文**——只生成跨章待办清单。"跨章机器改写语境依赖强"是既有拍板，画卷预览不得诱导"全书一键换词"。
2. **画卷是视图不是正本**：按需重算（纯函数），不落第二份事实源；重算不许抹掉教师决定（稳定 ID=词+章+层+段，从既有台账/标记带回复现状态）。
3. **词形归并口径唯一**：走引擎 `textpipe.hitOrigin`（表面形/IRR/剥变形，与判定链同一套）；**词表外词不强行归并**——按表面形独立成键并如实标注（清洗线教训：没有验证网的归并必误杀）。
4. **义项路由前置**：批量补注遇多义词且路由表有多个义项而无教师选择时，**拒绝该词并点名**（宁拒勿错——词典分号双义禁直插的既有规矩）。
5. **性能参照性能基线口径**：全书纯函数重算硬阈值 200ms（与 O5 基线同尺度），AF 十章×三层实测数记录进交付报告。
6. **同段倒挂/跨章重复注/专名排查/复现统计是同一张地图上的查询**——本计划建成后，验收 v2 的同段倒挂检查与其统一为画卷切片的事**只立备案不本轮做**（避免动冻结标准）。

## 项 1 · 引擎纯函数 `src/core/concordance.ts`（一切消费者的地基）

| # | 标准 | 机器查法 |
| --- | --- | --- |
| 1a | `buildConcordance(chapters)` → `Map<baseForm, Occurrence[]>`；Occurrence 含 章/层/段ID/含词句截断/文中形/是否已注 | `tests/concordance.test.ts`：构造 3 章×2 层、目标词两种形（wolf/wolves，词表含 wolf）→ 归并同键、2 条出现记录字段齐 |
| 1b | **词形归并口径唯一**：baseOf 走 `textpipe.hitOrigin`，本模块不自写剥变形 | 静态扫描测试：concordance.ts 无 `(endsWith('s')\|endsWith('ed')\|endsWith('ing'))` 类本地实现（纪律扫描，参照章号正则守卫的先例） |
| 1c | 词表外词不归并：known 不含 → 按表面形独立成键（防 bathroom→john 式假归并） | 测试：两个形似词在词表外 → 两个键，各带"未归并"标记 |
| 1d | 已注判定：`word（中文）` 处 `annotated=true`，同词裸处 false | 测试双向 |
| 1e | 聚合查询：`wordChapterMatrix`（词→章分布，复现统计用）、`properSuspects`（≥2 章首现大写、不在专名表与词表 → 候选；**句首大写不算**，用 align 的句首白名单口径）、`annotationDebt`（词在某层已注、其它层/章未注 → 债务清单） | 各 ≥2 例：命中例 + 零误报例（句首大写、专名表内词、单章词不进候选） |
| 1f | 性能：全书重算 < 200ms | `tests/concordance.test.ts` 性能用例（合成 10 章×3 层文本）；AF 真文本（LAYERTEXT_AF_DIR）有则实跑记录耗时、无则 `t.skip()` 说出口 |
