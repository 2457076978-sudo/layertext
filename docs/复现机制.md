# 复现机制（已学词集 / 复现队列）——设计说明

> feature/reinforce 分支，2026-09-08 组合拳夜间 T3 交付。组合拳·招式三：词库从静态快照变为**随教学演化的状态机**。
> 背景：教师拍板"学生读完第 N 章=默认学会前一章目标词，后续文本定向复现"。

## 一、概念模型

```
阅读事件（读完第N章）──► 已学词集（auto）──► 复现队列（5-8词/篇，隔2-3篇，3次毕业）
      │                                            │
      ▼                                            ▼
访谈/听写/小测证实 ──► confirmed（升级）    下一章简化/质检时注入队列
      │                                            │
      ▼                                            ▼
  证伪 ──► 回退并记录                     ⑩复现命中指标（队列/命中/词次）
```

三层状态：`auto`（读了默认学会）→ `confirmed`（测验证实）→ 毕业（复现满 3 次且 confirmed）；教师可随时回退。

## 二、引擎能力（本分支已实现，假数据测试 99/99 绿）

QC 引擎新增 `reinforceWords` 输入（`QcOptions`）：

1. **OOV 豁免**：队列词并入已知集，不再计为生词（生词率下降——"学了"直接改变难度口径）；
2. **⑩复现指标**：报告新增 `⑩复现词命中(队列/命中/词次)` 与 `复现命中词` 清单——命中按**词形家族**计词种（care 命中 cared/caring），词次计重复强度；
3. **旧 schema 零变化**：不传队列时结果与报告和 main 完全一致（双引擎对照/eval 基线不动，已回归验证）。

### 入口

- **CLI**：`node dist/src/cli.js qc <md> --vocab 词库.csv --reinforce 已学词.txt`
  - 队列文件宽容格式：纯文本一行一词 / `1. word` 编号 / CSV·TSV 首列（自动剥表头、# 注释、去重、多词短语整词保留）
- **MCP**：`layer_qc` 工具新增可选参数 `reinforce: string[]`
- **生成侧注入规划器**：`node tools/reinforce_plan.mjs <下一章.md> <已学词.csv>` —— 输出①本篇已自然复现词②需注入的缺席词③可直接贴进 AI 改写约束的中文注入指令（2026-09-08 交付；AF ch3 实证：⑩命中 5→11 词种、零黑名单，见班级画像 `演练_生成侧注入_v0.1.md`）
- **App**：暂未接线（见第四节）

## 三、班级画像对接约定（数据侧只存本地，红线）

画像文件：`01-教学工作/班级画像/画像_九3九4_v0.1.json`（**永不进本仓库**）。
每生字段：`已学词集 { 词: {source, since, hits} }`、`复现队列 [{词, 词形家族, 已复现次数, 下次复现篇序, 毕业}]`。

导出与回写脚本已交付（工程化轮，2026-09-08，本地数据侧不进本仓库）：

```
画像 JSON ──► 班级画像/画像_已学词导出.py ──► <层|生>_已学词.csv（首列=词）──► CLI --reinforce / MCP reinforce
质检报告⑩ ──► 班级画像/画像_复现回写.py apply ──► 画像 hits+1/间隔重置/毕业（每次写入自动备份 _历史/）
```

生成侧闭环（AI 简化下一章时）：

1. 读画像队列，取本篇应复现 5-8 词（按"下次复现篇序"到期者）；
2. 词注入简化约束（要求目标词在语篇中自然出现 1-2 次）；
3. 质检时传同一队列 → ⑩指标即"复现达标度"（命中≥5 且词次≥8 为达标带，参数可调）；
4. 产出后回写画像：hits+1、更新篇序、3 次毕业。

## 五、教学参数（默认值，教师在画像中可改）

| 参数 | 默认 | 依据 |
|---|---|---|
| 每篇复现词数 | 5-8 | 与 B 版词卡密度同量级，避免复现喧宾夺主 |
| 同词复现间隔 | 隔 2-3 篇 | 艾宾浩斯式间隔，2 天/2 篇双轨 |
| 毕业条件 | 3 次命中 + confirmed | 听写证实优先于频次 |
| 队列优先级 | 词形/听写薄弱生 → 词形家族优先 | 组合拳 T1 诊断：词形 20 人/听写 16 人是最大红旗带 |

## 六、边界与诚实口径

- "读了=学会"是**假设**（auto），非实测；confirmed 需测验证据。10 月试读 T1-T6 信号回收后校准。
- 复现命中指标度量的是**文本侧**的词重现，不等于学生掌握；掌握真值仍以听写/小测为准。
- 本分支只动引擎/CLI/MCP 三处 + 测试；eval 金标准与双引擎对照不受影响（回归已验证）。
