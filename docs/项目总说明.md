## 一、一句话

**把"一篇英文原著简化成学生能读的版本"从混乱的手工流程，变成有质检、有人机协作审校、
全程可审计的桌面工具。**

英文：LayerText turns "simplifying an English book for my students" from a messy manual process
into a tool with automated quality checks, human-in-the-loop review, and a full audit trail.

---

## 二、给谁用 / 它不是什么

**唯一目标用户**：把英文原著/分级文本简化成学生能读的版本、给自己学生读的**英语教师本人**。

- 不写代码、不熟 AI 配置；验收标准是**第一次打开的英语教师不看文档能走通**
- 个人电脑单机使用；**全离线、数据本地存储、零遥测**
- 对"数据上传"高度敏感——学生相关材料绝不能出本机

**它不是什么**（这几条最容易被误解）：

- **不是给学生用的 App**：学生拿到的是导出的「学生版」文本/Word，不是这个工具
- **不是自动出题机**：出题是另一条线（`grading.ts` / `reviewgen.ts` 是辅助），主战场是"把文本调到学生读得动"
- **不替教师做判断**：AI 只出候选，**每条建议都先过本机质检引擎复核，最后由教师点头才生效**
- **不做难度分级**：不预设 A/B/C 等级，难度由**教师词库**锚定（见下）

---

## 三、难度观（理解这个项目的关键一条）

1. **难度由词库锚定，不由篇幅锚定。** 学生学过什么词，就简化到词库内——
   所以同一个班换一套词库，同一篇文章该注哪些词是会变的。
2. **简化与加注是两件事，分开报，不合成一个数。**
   - **简化**管句法与词汇**负荷**（生词率、句长、被动/定从/过去完成）
   - **加注**管即时**理解支架**（该注的词注出了多少 = 加注覆盖率）
   - A 层实测：**阅读负荷下降 28% / 理解支架覆盖率 96%**——A 层几乎全是"加支架"而不是"降负荷"。
     合成成一个"可读性分"会把这个区别抹平，所以**两条轴分开显示**。
3. **篇幅比例不是难度**：保留 85%/75%/60% 是参考，不是目标；为压篇幅删掉人物提示或原因，是坏产物。

## 四、它怎么转（一条数据流看全）

```
原文（.txt/.md/.docx/epub）
   │
   ├─ 教师词库（课标1600 ∪ 教材已学 ∪ 术语 ∪ 专名）   ← 难度由此锚定
   │
   ▼
三档产物（A层85 / M层75 / B层60）            ← 生成管线（可断点续跑）
   │
   ▼
机器判定（零 AI，确定性）
   ├─ 段级门禁      ：不达标就不许"完成"，落隔离区
   ├─ 风险队列      ：事实/语言类疑点，按 风险=概率×后果 排队
   ├─ 正本核对      ：教师词典登记过的词，产物里还在不在（**判据最硬**）
   └─ 补注候选      ：学生词库外的词，有没有拿到注释支持
   │
   ▼
待确认队列：三路合成**教师只需要点的一张表**（★正本加注词 / 引擎客观项 / 正本 / 补注）
   │
   ▼  教师点 ①补注 ②换成X ③忽略
校准台账（append-only 不可变事件）           ← 换版本能重放回来；①向下传播 ②只记下级待办 ③不传播
   │
   ▼
发布包（白名单 + 学生数据黑名单双重拦截）+ 溯源（哪次运行/哪个模型/哪版词库/谁改了什么）
```

**两条贯穿始终的纪律**：**事件是正本，视图可重建**；**重算不许抹掉人的决定**。

## 五、行话速查（新人/新 agent 第一份该看的表）

| 说法                      | 含义                                                                                                              |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **A层85 / M层75 / B层60** | 三档产物。"85/75/60" 是**保留原文篇幅的参考比例**，不是难度等级                                                   |
| **词库锚定**              | 难度由教师词库决定（学生学过什么），不预设难度分级                                                                |
| **正本**                  | 教师自己的词典/知识库/词表——它是**判定的权威来源**，产物要以它为准                                                |
| **补注 / 加注**           | 给难词加中文注释 `word（中文）`，确定性插入，不改句子                                                             |
| **加注覆盖率**            | 该注的词里注出了多少（分子/分母**必须成对出现**，只报分子就是事故）                                               |
| **段级门禁**              | 每段过一组规则号（`SENT-01` 超长句 / `ANNO-01` 漏注 / `ZH-01` 正文中文 / `FACT-*` 事实…）；blocker 不过就不算完成 |
| **风险队列**              | 机器判不准但后果重的疑点，按 `风险 = 概率 × 后果` 排序等人工                                                      |
| **待确认队列**            | 三路结论合成的一张表，App「检 → 待确认」                                                                          |
| **校准台账**              | 教师词/句级判断的 append-only 正本，换版本重放                                                                    |
| **决定日志**              | 风险队列上的采纳/退回（与校准台账是**两本账**）                                                                   |
| **运行清单 runId**        | 一次运行的身份证：哪次运行、哪个模型、哪版词库。发布必须指向确定的一次运行                                        |
| **发布包**                | 导出/核对/溯源三件事；**默认不含学生数据**                                                                        |
| **学生版**                | 给学生读的成品（去审校视觉、含生词注释）                                                                          |
| **主模型 / 辅助模型**     | 主模型（API）干主力活；**辅助模型**（本机小模型，可选）只干"短输入+任务单一+输出可机检"的映射类小活               |
| **本地助手**              | 管线侧的小模型用法：**只**做带句释词 / 句级拆句，不做判断                                                         |
| **冻结回放**              | 真项目的一份输入 + 冻结结论，每次跑测试逐项对数（守"报给教师的那些数"）                                           |
| **两轮调适制**            | 生成 → 教师读后一句话反馈 → 第二轮按维度复写；**最多两轮**，其余交教师                                            |
